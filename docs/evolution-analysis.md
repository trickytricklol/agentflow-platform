# 自进化实验分析

## 已完成实验

### 第一轮

- 8 条业务样本
- 5 个 Prompt 候选
- 模型：Ollama `qwen3:1.7b`
- 最高准确率：`0.50`

第一轮暴露出评估集问题：分类标签和工具名没有给出候选集合，小模型容易把任务当成开放问答。

### 第二轮

补充候选标签、工具白名单、输出格式和优先级范围后重新实验：

- 8 条业务样本
- 6 个 Prompt 候选
- 最高准确率：`1.00`
- 最低候选准确率：`0.625`
- 1 个候选准确率：`0.875`

结果说明：

1. Prompt 变异和 GP/Expected Improvement 流程能够运行。
2. 评估集约束清晰程度对小模型效果影响很大。
3. 当前评估集仍然偏简单，基础 Prompt 已经达到 1.00，因此还不能证明 Bayesian 优化带来了稳定增益。

## 是否继续实验

需要继续。下一轮应加入：

- 隐藏约束和多步任务
- 相似但容易混淆的分类样本
- JSON Schema 严格校验，而不是只检查关键词
- Tool Router 的 Top-K 命中率和误调用率
- Prompt Token 成本、延迟、重试次数
- 训练集/验证集分离，避免 Prompt 针对固定样本过拟合
- 至少 30~50 条业务样本后再判断优化收益

当前 MVP 结论：自进化框架已经具备可运行闭环，但还不能把两轮实验结果当作生产效果结论。

## 外部工具调用验收

从 BFCL `BFCL_v4_simple_python.json` 取 20 条样本测试 Tool Router：词法 Router Top-1 为 `0.65`，增加 Ollama `qwen3:1.7b` 语义精排后提升到 `0.70`。模型输出解析失败时自动回退词法结果。下一步应继续接入 Embedding Router、JSON Schema 参数校验，并用 BFCL 的多函数/并行切片验证。

JSON Schema 参数校验已接入：工具执行前检查 required、基础类型和未知字段。

并行工具执行器已接入：多个已选工具在独立线程中并发调用，单个工具失败不会吞掉其他工具结果。
